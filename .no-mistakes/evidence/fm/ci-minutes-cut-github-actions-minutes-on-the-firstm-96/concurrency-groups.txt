collision across workflows? no - every group string is distinct

Reading: two runs on the SAME pull request share one group and cancel-in-progress is
true, so a fix-round push cancels the superseded run. Every push to main lands in its
own github.sha-keyed group AND carries cancel-in-progress=false, so a default-branch
run can neither cancel another nor be cancelled.
